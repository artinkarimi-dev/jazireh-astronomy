# Contributions

Jazireh Astronomy is a real client project published as a source-available portfolio repository.

Public feature contributions, derivative implementations, and pull requests are not requested. A pull request does not grant permission to use or modify the project and may be closed without review.

For a security concern, follow the process in [`SECURITY.md`](SECURITY.md). For permission or portfolio-related questions, contact the repository owner through the GitHub profile associated with this repository.
