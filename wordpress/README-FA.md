# نسخه وردپرسی جزیره نجوم — مرحله اول

این نسخه، بخش اخبار پروژه React را به پنل واقعی وردپرس متصل می‌کند و ظاهر فعلی سایت را حفظ می‌کند.

## امکانات ساخته‌شده

- قالب اختصاصی `jazireh-theme`
- افزونه اختصاصی `jazireh-core`
- نوع نوشته اختصاصی اخبار علمی
- دسته‌بندی اختصاصی اخبار
- تصویر شاخص، خلاصه، متن کامل، زمان مطالعه و خبر ویژه
- داشبورد فارسی اختصاصی جزیره
- REST API سازگار با ساختار React فعلی
- نمایش اخبار وردپرس در صفحه اخبار، جزئیات خبر و صفحه اصلی
- ثبت چهار خبر نمونه هنگام فعال‌سازی افزونه
- پشتیبانی از مسیرهای داخلی React در وردپرس

## نصب روی XAMPP

1. یک وردپرس خام نصب کنید.
2. پوشه `jazireh-theme` را در مسیر `wp-content/themes` کپی کنید.
3. پوشه `jazireh-core` را در مسیر `wp-content/plugins` کپی کنید.
4. وارد پیشخوان وردپرس شوید.
5. افزونه «Jazireh Core» را فعال کنید.
6. قالب «Jazireh Astronomy» را فعال کنید.
7. از تنظیمات پیوندهای یکتا، یک‌بار روی «ذخیره تغییرات» بزنید.
8. در پوشه `frontend` دستور زیر را اجرا کنید:

```bash
npm install
npm run build:wordpress
```

خروجی React مستقیماً داخل پوشه `dist` قالب ساخته می‌شود.

## مدیریت اخبار

در پیشخوان منوی «جزیره» و «اخبار علمی» اضافه می‌شود. برای هر خبر این موارد قابل مدیریت است:

- عنوان
- خلاصه
- متن کامل
- دسته‌بندی
- تصویر شاخص
- زمان مطالعه
- حالت خبر ویژه
- پیش‌نویس یا انتشار

## آدرس API

```text
/wp-json/jazireh/v1/news
/wp-json/jazireh/v1/news/{slug}
/wp-json/jazireh/v1/home
```

## نکته معماری

در این مرحله فقط اخبار به وردپرس منتقل شده‌اند. ویدیوها، تصویر روز، وضعیت آسمان و اجرام فضایی همچنان از API قبلی یا اطلاعات fallback پروژه استفاده می‌کنند تا تبدیل مرحله‌ای و کم‌ریسک باشد.
